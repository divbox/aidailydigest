OpenAI tells developers to trim prompt scaffolding built for older models
OpenAI is telling developers that prompt scaffolding written for older, dumber models is now actively hurting GPT-6 Astra's performance — bloated AGENTS.md files and vague task prompts waste memory and trigger the wrong behavior.
